# Bunny geometry

`bunny.off` is the bunny surface from the libigl tutorial data:
https://github.com/libigl/libigl-tutorial-data/blob/master/bunny.off
Downloaded 2026-11-20 from:
https://raw.githubusercontent.com/libigl/libigl-tutorial-data/master/bunny.off

The downloaded file is unchanged: 3485 vertices and 6966 triangular faces.
Trimesh verified a watertight, consistently oriented positive-volume solid.
The example rotates, uniformly scales and translates it in memory only.
This is a coarse bunny mesh, not the original high-resolution Stanford scan.
